# pi SDK 迁移与验收

日期：2026-11-15。基于现有 M4 实现迁移执行底座，不改变产品基线、数据库 Schema、Swift IPC 或配置格式。

## 实现边界

- 精确锁定 `@earendil-works/pi-coding-agent`、`pi-agent-core` 和 `pi-ai` 为 1.5.2，使用发布包公开接口，没有 fork 或导入内部文件。
- `runtime/src/pi.ts` 使用 `AgentSession`、`Agent` 和 `SessionManager.inMemory()`；每个活动 Run 独立重建执行投影。`service.ts` 保留调度、快照、预算、状态与流式消息提交，SDK 负责模型与工具的循环。
- 模型自定义流复用现有 `generate`，实际网络输入来自 Tandem 的已校验检查点，沿用三协议、原样 Base URL 前缀、指定端点凭据、不跟随重定向、响应限制与错误码。pi 自身的默认编程提示词和工具声明不进入模型请求；不增加模型列表发现或自动切换。
- 五个现有工具注册到 SDK，按顺序串行调用 `Execution.tool`；不注册默认 shell、读写文件工具。SDK 可能自动转换参数类型，因此执行时重新取持久化的原始参数；原有参数、目录身份和项目权限检查继续生效。
- 每次模型调用前预留预算、保存快照；模型响应先校验和落盘再交给 SDK 派发工具。每个工具结果先保存检查点再继续；SDK 生成的取消/校验错误不会替换原检查点。
- 审批等待、预算暂停、取消和退出停止后续模型及工具派发；错误继续使用原 `AppError`。工具自身的可观察失败保留为结果，不冒充完成。`complete_task` 保留原事务与完成标准检查；普通回答只结束 Run，不完成持久 Task。
- 恢复时使用公开的 `runToolCall` 执行检查点中未完成的调用，保留 call ID；已有 Invocation 结果去重。原生授权重验和预算累计沿用原实现，不新增用户消息，也不通过重新发模型请求重建工具意图。
- 资源加载器显式返回空资源；模型运行时使用内存凭据、无模型文件及无启动刷新；关闭压缩、重试、缓存预热与分析。不会发现或加载用户/项目的 pi 配置、MCP、skills、扩展和安装包。

## 构建与兼容

- 构建在独立 staging 目录通过 `--prod --offline --frozen-lockfile --ignore-scripts` 安装完整生产依赖图，复制依赖时保留 pnpm 相对符号链接及包内资源。运行应用无需全局 pi、pnpm、Node 或开发目录。
- `pnpm-workspace.yaml` 显式禁用 `@google/genai` 与 `protobufjs` 的安装脚本；本轮自定义模型流不使用其供应商实现。不启用额外安装脚本。
- SDK 发布的声明文件包含不带 JSON 导入属性的声明，另有可选 MCP 类型依赖，不能通过本项目 TypeScript 5.9 的依赖声明检查。配置 `skipLibCheck` 跳过外部声明检查；应用源码和适配接口仍使用 `strict` 类型检查，不修改 SDK 源码。
- 应用包许可从现有原生声明及生产依赖的 LICENSE/NOTICE 汇总；pi 发布包未附带根 MIT 文本，因此在原生声明中补入 v1.5.2 对应版权原文。
- 当前生产 Node 依赖约 153 MiB，应用包约 292 MiB。首轮优先保留完整依赖图以保证可移植性，没有裁剪 SDK 文件或增加打包器。

## 验收

所有模型测试使用本机模拟端点与隔离数据，不读取真实 Key，不调用付费模型。

- SDK 契约：串行工具批次、先提交检查点后执行、原始参数、审批/预算/取消/任务完成时停止、部分批次恢复、非法参数和未注册工具、原请求错误不重试。子进程配置恶意项目和用户资源，验证不会加载或发起后台请求。
- 实际执行增加原始行号为字符串的文件读取用例：即使 SDK 将其转为数字，原生桥接也不会收到读取请求，Invocation 保留原参数并返回 `TOOL_ARGUMENTS`。
- 保留三协议普通/流式契约和全部既有配置、路由、记忆、遗忘、隔离、审批、预算、任务修订、恢复及原生工具回归。
- 无窗口 Swift → Node 联调验证三协议、原生 Task、记忆证据/快照/遗忘、持久化、连接恢复、崩溃重启及退出清理。
- `test:bundle` 将应用完整复制到临时目录，校验所有符号链接位于包内，以最小 PATH 和内嵌 Node 运行同一无窗口联调。`test:lifecycle` 验证关最后一个窗口后任务完成、重开及完整退出后的 Node 清理。

| 检查 | 结果 |
| --- | --- |
| `pnpm run typecheck` | TypeScript 与 Swift 编译通过 |
| `pnpm run test` | 69 项 Node、19 项 Swift 测试及无窗口跨进程联调通过 |
| `pnpm run test:lifecycle` | 构建、关窗后台任务、重开、退出中断及内嵌 Node 清理通过 |
| `pnpm run test:bundle` | 隔离复制、包内链接及内嵌运行时联调通过 |
| `git diff --check` | 通过 |

本轮不包含 MCP/skills 管理界面、社区插件、模型网络层替换、真实云端兼容性验证或 Browser Use / Computer Use；签名公证和最低 macOS 实机验证仍按原有后续范围处理。
