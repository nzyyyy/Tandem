## 实施位置与边界

- `runtime/src/config.ts`：严格配置校验、0600 文件与临时文件、0700 目录、同目录原子替换、内容摘要版本检查、凭据脱敏。启动加载；设置保存或明确重载更新内存中的当前配置；没有文件监听。非法 JSON、未知版本或外部修改冲突不覆盖原文件。Settings 通过显式 `config.get` 读取编辑副本；平时的状态查询只返回模型摘要，不返回 Key。
- `runtime/src/model.ts`：直接使用平台 `fetch`，无新增 SDK 或运行时依赖；不自动重试、不自动切换 API、不跟随重定向。远程端点要求 HTTPS，HTTP 仅限 localhost / 回环地址。请求由本机历史重新构建，不使用远程会话或 previous_response_id。Anthropic 兼容实现固定使用 `anthropic-version: 2023-06-01` 的 Messages 契约与 `x-api-key`，不引入 2026 新版本专属能力。
- `runtime/src/store.ts`：Node 内置 SQLite 是唯一业务写入方；WAL、foreign_keys、Schema 版本和显式事务；单一 main Timeline 分配全局唯一 sequence。首次建立 M1 Schema，不涉及旧业务库升级；未知数据库版本拒绝启动，未就地执行未知迁移。
- `runtime/src/service.ts`：配置与聊天 RPC、模型目标绑定、Session / Surface 焦点、同 Session 串行队列、最多两个不同 Session 并行。请求接收时固定接入 ID、模型、协议、API 类型和 URL，不写入 Key；开始执行及重试前核对当前配置，地址或协议改变时明确阻塞。
- `native/Sources/TandemCore/AssistantModel.swift`：界面状态、类型化快照、发送与重试的请求幂等键、分页与断线后的增量恢复。
- `native/Sources/TandemApp/AssistantView.swift`、`ModelSettingsView.swift`：SwiftUI 侧栏、聊天、模型配置。M0 RPC 客户端增加互斥，避免心跳与界面请求交叉读写同一 Socket；帧上限从 M0 的 64 KiB 提高为 4 MiB，内容和分页另设更小上限。

## 一致性与恢复

1. 发送在单一事务中建立或选定 Session、更新当前 Surface 焦点、写入用户消息和对应回答占位、创建绑定模型的请求及消息变化事件。幂等键重复携带同一输入时返回原请求，输入不同时拒绝。
2. 下一请求轮到执行时才构建本地上下文，包含本条输入及前序已完成结果，排除后续排队输入及其他 Session；重试选用前序成功尝试，失败的部分输出不冒充成功回答。
3. 失败不会自动重试或换模型。重试关联原用户消息，不重复插入用户输入；默认仍绑定原模型，输入区明确手动选择后可换模型。同一失败尝试重复点击只建立一次重试。已有失败回答保留并标明失败。
4. 内容更新、请求状态与消息变化事件在事务中持久化。事件保存版本、类型、聚合 ID、关联 ID、原因、时间和消息引用，不另存一份正文。UI 以持久序号获取变化，合并同一消息的多次文本变化，避免逐 token 的旧事件拖延恢复；游标越界返回 GAP_REQUIRED 并重新载入快照。当前不裁剪事件，历史正文按需分页。
5. 完整退出取消在途请求并将排队/执行中工作标为 interrupted；异常退出留下的 queued/running 状态在启动时转为 interrupted，不自动派发。部分输出与历史保留，需手动重试。
6. Key 只落配置文件；请求构建、用户输入保存和模型输出保存执行已配置 Key 与常见 token 模式脱敏。错误使用固定错误码，不记录供应商错误正文或用户请求正文。云端实际数据保留依供应商政策，不声称本机删除可撤回远端数据。

## M1 的保守参数

当前话题路由仅使用明确控件、历史选择及少量保守短语（如“临时问”“插一句”“继续上次”），代码中已标记 shortcut。不宣称具备任意语义切换或歧义澄清能力；这些属于 M2 的 Interaction / Router / Snapshot。

输入最多 8000 字符，单次文本输出最多 32 KiB，模型响应读取最多 2 MiB，请求超时 90 秒；每次上下文最多最近 40 条因果消息且总计不超过 128 KiB，超限明确报错。这些是 M1 传输与资源保护上限，不是 M3 的 token/步骤/活跃时间预算系统。历史每页 10 条，最近话题列表最多 100 项；超过列表上限的历史消息仍保留。

本阶段不向模型声明可执行工具。适配器识别结构化 tool_calls / function_call / tool_use，并保留正确的调用 ID（Responses 使用 call_id）；收到工具请求时保留文本、标记 TOOLS_UNAVAILABLE，不执行也不伪造工具结果。Registry、审批、工具结果回传与完整工具循环属于 M3。
