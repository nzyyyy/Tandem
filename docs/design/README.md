# Tandem UI 视觉提案

设计稿基于 M2 功能和 SwiftUI 结构；已按此提案完成原生界面实现。三张图均为 2880 × 2080 PNG，窗口按 1312 × 820 pt 设计，周围底色、标题和说明属于展示画板，不进入应用。

## 视觉方向

安静、清晰的原生 macOS 工作台。统一浅灰绿中性色，青绿色只强调选中和主要操作；红色只用于错误或删除语义。保留系统字体、原生窗口按钮和 SF Symbols，不引入网页风格的大面积装饰。

当前问题来自源码检查：导航选中层级不明显；标题和工具行占用多层空间；消息里的模型、归属、纠正和上下文操作与正文争夺注意力；输入区堆叠多个选择器；项目与模型配置的长表单缺少清晰分组。没有启动应用，结论不代替运行截图审查。

## 页面与交互

### 对话

- 左侧保留对话、项目、模型设置和最近话题；明确区分所在页面与当前话题。
- 主区保留全局连续历史，顶部标明当前话题，消息旁仍可辨认话题归属。选中最近话题只恢复焦点，不将全局历史悄悄改为单话题列表。
- 项目归属保留为可点击标签；纠正记录放在消息的更多菜单中；执行上下文保留显式入口。归属纠正与原执行上下文不一致时，说明与“按当前归属重新处理”必须直接展示。
- 输入框上方保留上下文模式和项目选择。选择后显示“应用范围”，成功后才能替换已生效的范围；固定、隔离模式保持明显标识。未选择项目是有效选项。
- 输入框内分开输入正文、模型选择、临时插话和发送。临时插话与新话题是下一条消息的标记，启用时显示可取消状态，不能只藏在菜单里。存在被中断话题时展示“恢复原话题”。
- 全局历史筛选保持原有语义，包括未关联和已归档项目。模型名称与接入项都保留；长名称截断时提供完整提示。

### 项目

- 用列表选择项目，在右侧编辑名称和说明；新建进入空表单，不清空尚未保存的编辑而不提示。
- 活动与归档状态明确区分，归档后可恢复。
- 永久删除入口保留“预览”语义，随后完整呈现影响范围及确认，不与归档合并。
- 图中数量和项目内容均为示例，产品以真实数据呈现。

### 模型设置

- 默认模型独立为首组；接入项用列表选择，右侧呈现当前项的字段。
- 沿用已有协议、API 类型、URL、API Key、模型列表逐项添加与移除和添加/移除操作。默认模型保留“未设置”选项，不自动选择第一项。
- 所有接入项仍作为一份配置保存。切换项保留未保存编辑；重新加载或离开时若会丢失编辑，必须明确处理。
- 保存配置固定在工具栏。加载中、无可用 revision、保存冲突和保存结果就地显示；不掩盖已有并发版本保护。
- 保留 API Key 本机明文保存说明；稿中 URL 和模型名为示例，不表示新增服务或模型。

## 状态规则

| 状态 | 显示与行为 |
| --- | --- |
| 首次空白 | “从一个想法开始”及简短提示，保留输入区；未配置模型时提供设置入口 |
| 初始加载 | 内容占位和明确加载状态，配置尚不可用时禁止提交 |
| 待确认话题 | 原位置显示待确认输入、候选证据和明确选择按钮；不预选、不自动发送；隔离模式沿用候选权限限制 |
| 范围待应用 | 选择器旁出现“应用范围”，显示当前生效范围，失败不伪装成功 |
| 排队、生成中 | 就地标明状态和停止按钮，保留部分输出；不以占位替换已生成文字 |
| 取消、失败 | 文字解释配合状态色，保留输出与重试入口；可辨认使用原模型或所选模型重试 |
| 归属被纠正 | 保留原执行项目、纠正记录和重新处理入口 |
| 项目归档 | 明确“已归档”与恢复操作，默认活动列表收起 |
| 永久删除 | 完整预览影响范围，再独立确认；加载和执行期间禁止重复提交 |
| 配置冲突 | 行内说明外部修改与重新加载入口，不覆盖新版本 |
| 断开连接 | 侧栏状态和相关操作区同时说明，不展示“已连接” |

## 实施边界与适配

仅涉及 AssistantView、MessageView、ProjectView、ContextControls、PendingInteractionView、RunContextView、ModelSettingsView、ConnectionEditor 的展示层；窗口尺寸和工具栏如需调整再涉及 main.swift。复用 AssistantModel 的接口和行为，不改路由、IPC、数据库、凭据存储或业务权限。

窄窗口沿用 860 × 600 pt 最小尺寸：对话列收缩，工具条可换行；项目和模型设置改为选择器或单列主从导航；正文区域滚动，输入框及主要保存入口保持可用。文字支持系统动态设置和长中文内容，不以固定高度截断校验信息。

键盘焦点使用清晰强调色轮廓；选中态同时使用背景和字重；运行与错误状态同时使用文字，不能仅靠颜色。图标按钮保留可访问性名称与快捷键提示。图中边框为分组装饰，实际输入框需补足可辨认的控件边界和焦点状态。悬停仅做轻微背景变化，状态过渡约 150 ms，遵循减少动态效果设置。

静态稿展示浅色方案；实际界面使用适配深浅色的语义颜色，并在窄窗口改为单列选择与编辑。尚未启动应用验证实际显示和交互。

## 复现

在仓库根目录执行：

```sh
swift -module-cache-path /tmp/tandem-design-swift-cache docs/design/render.swift
```

使用 AppKit 离屏绘制，不启动应用或浏览器。渲染脚本对尺寸与输出数据做断言；三张 PNG 已逐张查看。实现已通过应用构建、33 项运行时测试、11 项 Swift 测试及 Swift → Node 无窗口联调；尚未进行窗口生命周期和人工视觉检查。
